# recipes

Snippets Java que ya funcionaron contra STAR-CCM+. Memoria del agente.

Formato de archivo: `<verbo>-<objeto>.java`, cabecera de 3 líneas:

```java
// QUE: crea una región MRF con rpm dados
// VERSION: 2606.0002
// FECHA: 2026-10-25
```

El cuerpo es lo que va dentro de `execute()`, sin la clase. `run_java` lo envuelve.

Las recetas con `// ESTADO: no verificado` vienen de memoria de Claude y hay que probarlas
antes de confiar. Al verificarlas, quitar esa línea.
